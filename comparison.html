Decode speed vs used context — the 8 tok/s usability floor (2026-08-28, limit 25000)

Why this axis exists: decode speed falls as the KV cache fills — a real coding session measured 1.7 tok/s at 135K used tokens on a config whose near-empty benchmark said 62. Context maxima alone are storage, not speed. Each model is swept with an append-only growing prompt (perfect cache reuse) until decode drops under the user's 8 tok/s floor or the server runs out of memory. The floor, not the window, is where pi's compaction threshold belongs — and capping the window also returns wired memory to the system.
