## Step 5 Design Scope & Targets

1. **Aesthetic direction:** Load the `frontend-design` skill first. Give the site an intentional, technical-benchmark publication identity (clean typographic hierarchy, disciplined color tokens for light & dark mode, zero generic SaaS gradients or template bloat).
2. **Global Sidebar Proof Widget (`ProofSidebar.vue`):** Turn the minimal sidebar link into a crisp, unmistakable proof card (`325h+ benchmarked`, scored runs / models / machines / tool calls) that reads cleanly in both light and dark mode on desktop and mobile drawer.
3. **Homepage (`site/index.md`) & Setup Pages (`site/setups/<slug>/index.md`):**
   - Present machine winners and the 4 empirical laws with clear visual structure (compact winner cards / callout grid) without adding prose bloat (keep within `docs/agents/site-writer.md` word caps).
   - Keep the homepage immediately scannable: scale proof → winners per machine → best per model → 4 laws.
4. **Tables, Pills & Scroll Affordances (`custom.css`, `ModelSpec.vue`, `ScoreCell.vue`, `TokCell.vue`, `CurveCell.vue`):**
   - Remove the perpetually pulsing `⇢` animation (`table-hint-pulse 1s linear infinite`) on non-overflowing tables; use a clean conditional scroll cue or subtle edge fade only when a table actually overflows.
   - Calm down visual density on `site/benchmarks/mendel.md` (clear hierarchy across Score, Ctx/speed, Bugs, and Stats pills so rows breathe without visual fatigue).
   - Polish `site/files/<id>.md` auto-generated metadata & INI preset presentation if needed (via CSS or `tools/gen-tables.mjs` markup — never hand-edit `site/files/*.md`).
5. **Decode-Speed Visuals (high-value optional upgrade):**
   - Consider a lightweight, zero-dependency SVG chart component reading `data/setups/*/models.json` `curves[]` (or generated build-time JSON) to visualize decode speed vs. context depth (with the `8 tok/s` usability floor clearly marked) on `site/benchmarks/decode-speed.md` and `site/models/<slug>.md`.
6. **Responsive & Theme QA:**
   - Test locally via `npm run dev` with `playwright-cli` (load skill first) across desktop (`1280px`) and mobile (`390px`) in both **light** and **dark** mode on: Home, both Setup pages, 2 Model pages, 1 `/files/*` page, Benchmarks (`/benchmarks/`, `decode-speed`, `mendel`), and `/method/`.
