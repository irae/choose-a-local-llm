Summary

MoE (35B total, ~3B active) + MTP is the new speed king: 68 py / 74 js tok/s at draft depth 3 — 1.5× Gemma-12B, 4× dense Qwen3.8 — with the strongest base-model coding pedigree tested (73.4 SWE-bench Verified). The wired limit is now 25000 (27000 made the machine too slow for normal use; 24000 capped context at 40K): single-session context reaches 96K, down from 208K. Decode collapses to ~17 tok/s once ~30K+ tokens are in use — accepted, since the initial session is where speed matters most. Initial EvalPlus score below — deflated by a harness bug, not yet fair.
